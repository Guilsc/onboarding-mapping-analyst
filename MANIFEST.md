## Operating principle

The user can begin from a supported AI surface without knowing the best model/Skill/workflow in advance.

The solution determines:

Task Intent  
→ Mapping Workspace  
→ Complexity / Consequence  
→ Relevant Skills  
→ Doppelganger (optional)  
→ Governance.

The solution remains specialized in data-mapping work.
