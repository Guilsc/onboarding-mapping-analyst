# Default Role Lens

A default Role Lens is optional.

Use it only when the current task does not clearly call for a different professional perspective.

A task-specific Lens may temporarily override this default without changing the profile.

# Profile Learning

The agent may propose a Profile Update Candidate when a repeated useful preference is observed.

Do not modify this profile silently.

Persist an update only after the user confirms it.

# Boundaries

This profile may adapt analysis emphasis, detail, comparison style, and presentation.

It must never:
- override mapping evidence;
- redefine canonical taxonomy;
- change Approved Master rules;
- weaken validation;
- approve a Master/version;
- modify shared Mapping Skills.
