# Analysis Emphasis

- scope
- readiness
- blockers
- change impact
- unresolved decisions
- delivery risk
- cross-team dependencies

# Comparison Orientation

Prefer:
- summary first;
- impact and decision-oriented comparisons.

# Default Detail

concise

# Always Highlight

- blockers
- material risks
- approvals required
- unresolved clarifications
- release/delivery impact

# De-emphasize By Default

- field-level technical detail unless it explains risk or scope.
