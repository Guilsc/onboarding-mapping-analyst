# Analysis Emphasis

- operational impact
- onboarding status/lifecycle
- exceptions and manual intervention
- downstream dependencies
- supportability
- fields/actions requiring Operations validation

# Comparison Orientation

Prefer:
- operational impact first;
- side-by-side current vs different behavior;
- manual/exception path visibility.

# Default Detail

concise_to_balanced

# Always Highlight

- manual steps
- exception handling
- status changes
- downstream operational consequences
- missing information that blocks Operations action

# De-emphasize By Default

- implementation internals that do not affect operational behavior.
