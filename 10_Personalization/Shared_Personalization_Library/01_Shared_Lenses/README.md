# Shared Lenses

Shared Lenses are reusable professional perspectives.

Starter lenses:
- Business Analyst
- Operations
- QA
- Developer / Integration
- PM / DM

A Shared Lens may be:
- explicitly selected by the user;
- automatically selected when the current task strongly and unambiguously calls for that professional perspective;
- used as a fallback/default perspective when explicitly associated with a user/profile and the task itself is neutral.

Do not blend multiple lenses by default.

If a user explicitly asks for multiple perspectives, run each lens separately and combine the findings rather than merging the lens instructions.

Shared Lenses never change mapping evidence, canonical rules, validation, or governance.
