# Analysis Emphasis

- expected behavior
- test scenarios
- edge cases
- required/conditional behavior
- regression impact
- test data requirements
- observable outcomes

# Comparison Orientation

Prefer:
- scenario-based comparisons;
- expected vs observed behavior;
- coverage and regression implications.

# Default Detail

balanced_to_detailed

# Always Highlight

- ambiguous expected results
- missing test conditions
- negative/edge scenarios
- regression-sensitive changes
- data prerequisites

# De-emphasize By Default

- design rationale that does not change expected behavior.
