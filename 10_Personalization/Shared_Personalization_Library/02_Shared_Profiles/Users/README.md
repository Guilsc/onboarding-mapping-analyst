# Shared User Profiles

This folder contains Personal Analysis Profiles intentionally shared by real users.

Recommended structure:

```text
Users/
└── <User_Name>/
    └── profile.md
```

Rules:
- profiles are private by default before publication;
- publication into this folder is explicit;
- never auto-select another person's profile from task content, role, or name similarity;
- a Shared User Profile may be used when explicitly selected or explicitly bound to that user;
- the profile may be combined with one Shared Lens;
- profile preferences never change mapping truth or governance.
