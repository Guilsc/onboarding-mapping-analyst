# Incoming / New Evidence

Writable contribution area for new historical mappings or reference material.

Normal users may add new evidence here without modifying the managed source library.

The agent should:
1. register the new source;
2. classify it;
3. compare it with current governed knowledge;
4. determine whether it is supporting evidence, an exception, a conflict, or a potential Master Change Candidate.

Adding a file here never changes an Approved Master automatically.
