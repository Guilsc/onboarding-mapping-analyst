## How the agent uses it

When the user does not provide another mapping source, the agent should use this shared workspace as the default mapping source.

The shared workspace may contain:
- Current Approved Master Index
- Approved Masters
- Draft Masters
- Registries
- Historical Source Library
- Production Evidence
- Incoming / New Evidence
- Request Outputs

The shared link is a pointer, not a copy of the workspace.

Normal users should consume governed shared files without modifying protected content. New evidence should be contributed through the workspace's Incoming / New Evidence locations.
