- **Working Edit History:** Google native Docs / Sheets / Drive version history when available

## Optional Personalization

- **Personalization Mode:** None / Personal Profile / Shared Personalization
- **Personal Profile Path:** Optional
- **Shared Personalization Path:** Optional
- **Role Lens Path:** Optional

Personalization is not part of mapping truth. It only adapts analysis emphasis, detail, comparison style, and presentation.

## Interpretation

Missing optional locations do not block source discovery.

A new Custom Mapping Workspace can begin with only a source location.

A missing/inaccessible personalization file does not block mapping work; continue with standard OMA behavior.

The agent should discover what exists before requiring additional structure.
