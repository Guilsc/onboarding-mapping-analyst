# Bootstrap Checklist

## Package setup

- [ ] Unzip the package
- [ ] Keep Agent Core, Skills, templates, and workspace guidance intact
- [ ] Configure the Recommended Shared Workspace link in `00_Workspace/SHARED_MAPPING_WORKSPACE.md`

## Recommended Shared Workspace

- [ ] Confirm shared source/evidence location
- [ ] Confirm Approved/Draft Master locations
- [ ] Confirm Current Approved Master Index
- [ ] Confirm registry location
- [ ] Confirm Incoming / New Evidence location
- [ ] Confirm default Request Outputs location
- [ ] Configure permissions so governed files are protected

## First canonical bootstrap, only when needed

- [ ] Run independent Source Discovery
- [ ] Discover candidate mapping families
- [ ] Analyze Salesforce progressively
- [ ] Analyze Workfront when relevant
- [ ] Reconcile fields/cross-object behavior
- [ ] Compare prior hypotheses only after independent discovery
- [ ] Produce Analysis Review
- [ ] Resolve material clarifications
- [ ] Generate V1 Draft
- [ ] Explicitly approve V1
- [ ] Register/update Current Approved Master Index

## Custom Mapping Workspace

A user does not need the full shared structure to start.

Minimum:
- [ ] provide mapping folder/files
- [ ] identify them as a separate Custom Mapping Workspace
- [ ] let Source Discovery inspect what exists

Optional:
- [ ] add Salesforce/Workfront examples
- [ ] add a Workspace Manifest
- [ ] define an Outputs location
- [ ] create a Current Approved Master Index after a governed Master exists

## Normal use

- [ ] select/resolve workspace
- [ ] use current Approved Master if available
- [ ] otherwise use Build / Discover
- [ ] keep workspace outputs and learning isolated by default
