# Gemini + Gemini Notebook Working Pattern

User / BA
→ Gem interprets request
→ Router identifies workflow
→ relevant Skills selected
→ source-heavy work goes to Gemini Notebook
→ findings summarized into Analysis Review
→ BA decision
→ approved result persisted in Drive
→ future Gem/Notebook sessions consume approved shared knowledge

Important:
Notebook conclusions do not become durable merely because they appeared in a conversation.

Persist validated conclusions in registries and/or Approved Master artifacts.
