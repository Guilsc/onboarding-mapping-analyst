# Knowledge Registries

The workbook in this folder is the durable shared memory layer.

Tabs:
1. Taxonomy
2. Decisions
3. Sources & Evidence
4. Mapping Rules
5. Exceptions
6. Clarifications
7. Learning & Errors
8. Versions

Use the registries to preserve approved knowledge and decisions across users.

The **Versions** tab tracks logical OMA mapping versions and governed promotion decisions. It should not duplicate every native Google file revision or working edit.

Do not treat every intermediate AI hypothesis as registry-worthy.

Persist what changes future reasoning.

The Approved Master remains the primary human-facing mapping artifact; registries explain why the project believes what it believes.
