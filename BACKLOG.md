# Onboarding Mapping Analyst Backlog

This backlog captures deferred capabilities that are intentionally outside the current implementation scope.

## Future Version Candidates

### Direct Shared Library Navigation / Destination Shortcuts

**Status:** Backlog  
**Priority:** Could / Future Version

**Goal**

Make Shared Personalization Library navigation easier by allowing users to open the exact destination required for a Doppelganger action instead of browsing the library manually.

**Potential future behavior**

- Open Shared Lenses directly.
- Open Shared Profile Samples directly.
- Open Shared User Profiles directly.
- Open the correct profile publication destination when a user chooses to share a profile.
- Use destination-specific shared-folder pointers/links when the execution surface supports them.
- Consider shortcuts or UI actions only in a future version.

**Current version**

No dedicated interface is required.

Users may provide/select the Shared Personalization Library path manually. The current architecture remains file/path based and works without direct-navigation controls.
